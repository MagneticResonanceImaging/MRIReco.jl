# MRIFiles

MRIFiles handles raw data files, for example ISMRMRD files (`ISMRMRDFile`) and Bruker datasets (`BrukerFile`). MRIFiles depends on MRIBase. It has to be loaded with `using MRIFiles`, because MRIReco does not depend on it.

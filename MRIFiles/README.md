# MRIFiles

[![](https://img.shields.io/badge/docs-dev-blue.svg)](https://magneticresonanceimaging.github.io/MRIReco.jl/dev/API/MRIFiles/)

MRIFiles reads and writes [ISMRMRD](https://ismrmrd.readthedocs.io/) files and reads data from Bruker scanners. It is one of the packages of [MRIReco.jl](https://github.com/MagneticResonanceImaging/MRIReco.jl), builds on MRIBase and is registered on its own:

```julia
using Pkg
Pkg.add("MRIFiles")
```

The [documentation of MRIReco.jl](https://magneticresonanceimaging.github.io/MRIReco.jl/dev/) covers all packages of the repository, and its [API reference for MRIFiles](https://magneticresonanceimaging.github.io/MRIReco.jl/dev/API/MRIFiles/) lists the functions of this package.

Questions are welcome in the [discussions](https://github.com/MagneticResonanceImaging/MRIReco.jl/discussions) and bug reports in the [issues](https://github.com/MagneticResonanceImaging/MRIReco.jl/issues) of the repository. The [contributing guide](https://github.com/MagneticResonanceImaging/MRIReco.jl/blob/master/CONTRIBUTING.md) explains how to develop and test the packages.

MRIReco

MRIReco provides the image reconstruction of the framework. Of the packages in this repository, it depends on MRIBase and MRIOperators. It re-exports both, together with RegularizedLeastSquares.jl and AbstractImageReconstruction.jl, so the data types, encoding operators, solvers, regularization terms and the functions for reconstruction plans are available after using MRIReco. MRIFiles, MRISampling, MRICoilSensitivities and MRISimulation are independent of MRIReco and have to be loaded separately.

Reconstruction

MRIReco.reconstruction — Function
reconstruction(acqData::AcquisitionData, recoParams::Dict)

Performs image reconstruction of an AcquisitionData object. Parameters are specified in a dictionary.

Reconstruction types are specified by the key :reco. Valid reconstruction names are:

  • "direct" - direct Fourier reconstruction (default)
  • "standard" - iterative reconstruction for all contrasts, coils & slices independently
  • "multiEcho" - iterative joint reconstruction of all echo images
  • "multiCoil" - SENSE-type iterative reconstruction
  • "multiCoilMultiEcho" - SENSE-type iterative reconstruction of all echo images
  • "multiCoilMultiEchoSubspace" - SENSE-type iterative reconstruction of the coefficient maps of a temporal basis

The dictionary is merged into the defaults of defaultRecoParams, and :reconSize defaults to the encoding size of acqData. reconstruction then loads the plan of the reconstruction type with MRIRecoPlan. For the iterative reconstructions, a few keys first select the type of a parameter: :densityWeighting => false selects UniformWeightingParameters, :weights selects CustomWeightingParameters, :encodingOps selects CustomEncodingParameters, and a :sparseTrafo with an operator selects CustomSparsityParameters; "direct" does not support these keys and warns that it cannot set the parameter they select. reconstruction then sets the parameters of the same name as the other keys, for example iterations of LeastSquaresSolverParameter for :iterations, and runs the plan.

Other keys that the plan does not have are ignored. If the value of such a key is a parameter object such as UniformWeightingParameters(), an algorithm or a plan, reconstruction warns; with ENV["JULIA_DEBUG"] = "MRIReco", it lists the remaining keys that the plan does not have, :densityWeighting included.

source
reconstruction(acqData::AcquisitionData, recoParams::Dict, filename::String;
               force=false)

This method is meant to save the result of reconstruction(acqData, recoParams) in the file filename, or to load it from there if force=false and the file exists. The functions it calls for this are no longer part of MRIReco, so it throws an UndefVarError: right away if force=false and the file exists, otherwise after the reconstruction.

defaultRecoParams() -> Dict{Symbol, Any}

Return the default parameters of reconstruction: :reco => "direct", :reg => L1Regularization(0.0), :normalizeReg => NoNormalization(), :solver => ADMM, :rho => 5e-2, :iterations => 30 and :arrayType => Array. reconstruction merges the given dictionary into them.

Reconstruction Plans

reconstruction translates the parameter dictionary into a reconstruction plan of AbstractImageReconstruction.jl and runs it. A plan for each reconstruction type is stored in reco_plans/ and can be loaded with MRIRecoPlan, e.g. MRIRecoPlan("multiCoil"), or run directly with reconstruct("multiCoil", acqData; kwargs...).

AbstractImageReconstruction.reconstruct — Method
reconstruct(name::AbstractString, acqData::AcquisitionData; modules = getMRIRecoPlanModules(), kwargs...)

Perform a reconstruction of acqData with the RecoPlan specified by name. Additional keyword arguments can be passed to the reconstruction plan. modules are the modules whose types the plan file can use, see addMRIRecoPlanModule.

The plan is looked up as the file name.toml in the folders added with addMRIRecoPlanPath, the last added first, and then in the folder reco_plans of MRIReco. Alternatively, name can be the path of a plan file.

Examples

Ireco = reconstruct("standard", acqData; kwargs...)

MRIReco.MRIRecoContext — Type
MRIRecoContext{D, arrT, S, Acq}

Container for reconstruction context parameters that are used throughout the reconstruction pipeline. Uses a ScopedValue for task-local access.

Fields

  • reconSize::NTuple{D, Int64} - Size of the reconstructed image
  • arrayType::Type{arrT} - Array type for computation (Array, JLArray, etc.)
  • storageType::Type{S} - Storage type for operators
  • acqData::Acq - Acquisition data or nothing, provides metadata like trajectory info
  • red3d::Bool - true if 3D-encoded data was converted to 2D slices and the user gave a 3D reconSize; user-supplied volumes (e.g. sensitivity maps) are then in 3D order and need to be permuted

Usage

# Set the context for reconstruction
ctx = MRIRecoContext((128,128), Float64, Array)

# Or with acquisition data
ctx = MRIRecoContext((128,128), acqData, Array)

# Using with() to set scoped value
with(MRIRECO_CONTEXT => ctx) do
    # reconstruction code
end

# And then access anywhere in the reconstruction pipeline
function foo(sparsity_params)
    rs = ctx_reconSize()  # Get from scoped value
    ad = ctx_acqData()    # Get acquisition data if needed
    # ...
end

MRIReco.AbstractIterativeRecoParameters — Type
AbstractIterativeRecoParameters <: AbstractMRIRecoParameters

Abstract base type for iterative reconstruction algorithm parameters. Subtypes must implement callable methods for use with AbstractIterativeMRIRecoContextParameter.

Required Callable Interface

Allocation

(params)(algo, reconSize) -> (Ireco, indices, weights, extra...)

Allocates the output array and returns iteration indices and weights.

  • algo - The algorithm
  • reconSize::NTuple{D, Int64} - Reconstruction size
  • Returns a tuple of (Ireco, indices, weights, extra...) where:
    • Ireco::Array{Complex{T}} - Output image array
    • indices - CartesianIndices for iteration
    • weights - Sampling weights
    • extra... - Optional additional data (e.g., decorrelatedSenseMaps, L_inv for coil recon)

Loop Body

(params)(algo, Ireco, index, weights, extra...)

Called once per iteration index. Writes results to Ireco.

  • algo - The algorithm
  • Ireco - Output array to write to
  • index::CartesianIndex - Current index, such as (rep, slice)
  • weights - Sampling weights from allocation
  • extra... - Optional additional data from allocation

Finalization

(params)(algo, Ireco) -> result

Finalizes and returns the reconstruction result.

  • algo - The algorithm
  • Ireco::Array{Complex{T}} - The filled output array
  • Returns final result (typically AxisArray)

MRIReco.EncodingParameters — Type
EncodingParameters{C} <: AbstractMRIRecoEncodingParameters

Parameters for computing encoding operators from acquisition data.

Type Parameters

  • C - Type of correctionMap, an AbstractArray{<:Complex} or Nothing

Fields

All fields are nothing by default, and the operator then uses its own default given below.

  • correctionMap::C - Complex correction map z of two-dimensional data for off-resonance and relaxation, in the precision of the data, see Correct Off-Resonance (default: none)
  • method::Union{String, Nothing} - Approximation of exp(-z t), where t is the sampling time, for a map that varies within each slice and sampling times that are not all equal: "nfft", "leastsquare", "hist", which works for a map with only an off-resonance part, or "svd", which works for double-precision data, a map with a spatially varying off-resonance part and profiles with the same sampling times and about ten or more samples per term (default: "nfft"), see FieldmapNFFTOp
  • toeplitz::Union{Bool, Nothing} - Whether the normal operator uses the Toeplitz approach (default: false)
  • oversamplingFactor::Union{Float64, Nothing} - NFFT oversampling factor (default: 1.25)
  • kernelSize::Union{Int, Nothing} - NFFT kernel size (default: 3)
  • K::Union{Int, Nothing} - Number of terms of "leastsquare" and "hist" and maximum number of terms of "svd" (default: 20); "nfft" determines the number itself
  • K_tol::Union{Float64, Nothing} - Tolerance with which "svd" chooses the number of terms (default: 1e-3)

method, K and K_tol only take effect with a correction map, and toeplitz, oversamplingFactor and kernelSize only for non-Cartesian data without a correction map.

Callable Interface

(ep::EncodingParameters)(algo, slice::Int)
(ep::EncodingParameters)(algo, slice::Int, senseMaps)

Returns

  • The encoding operators of the given slice: one per contrast for the reconstructions that treat the contrasts separately, and otherwise one for all contrasts. The second form, used by the reconstructions with coil sensitivities, includes the sensitivities.

Note

  • Gets the data, the reconstruction size and the storage type from the MRIRecoContext of the reconstruction

Example

ep = EncodingParameters()

# With a correction map
ep = EncodingParameters(; correctionMap = cmap, method = "leastsquare", K = 10)

MRIReco.LeastSquaresSolverParameter — Type
LeastSquaresSolverParameter{SL, R, T} <: SolverParameters

Parametric solver parameters for iterative MRI reconstruction using RegularizedLeastSquares.

Type Parameters

  • SL - Solver type: ADMM, CGNR, FISTA, POGM, OptISTA or SplitBregman
  • R - RegularizationParameters type
  • T - Floating-point type of rho and the tolerances

Fields

Except for solver and regParams, a field is passed to the solver as the keyword argument of the same name, but only if it is not nothing and the solver takes that keyword; otherwise the solver uses its own default.

  • solver::Type{SL} - Solver type (default: ADMM)
  • regParams::R - Regularization terms and their transforms (default: RegularizationParameters())
  • normalizeReg::AbstractRegularizationNormalization - Scaling of the weights λ of the terms: NoNormalization(), MeasurementBasedNormalization() or SystemMatrixBasedNormalization() (default: NoNormalization())
  • iterations::Int - Maximum iterations; for SplitBregman, the outer iterations (default: 30)
  • rho::T - Penalty parameter of ADMM and SplitBregman and step size of FISTA, POGM and OptISTA (default: 5e-2). FISTA, POGM and OptISTA always receive it, so they do not determine the step size themselves.
  • iterationsInner::Union{Int, Nothing} - Inner iterations of SplitBregman (default: nothing)
  • iterationsCG::Union{Int, Nothing} - CG iterations of ADMM and SplitBregman (default: nothing)
  • absTol::Union{T, Nothing} - Absolute tolerance of ADMM and SplitBregman (default: nothing)
  • relTol::Union{T, Nothing} - Relative tolerance (default: nothing)
  • tolInner::Union{T, Nothing} - Tolerance of the CG iterations of ADMM and SplitBregman (default: nothing)
  • verbose::Bool - Print progress in all solvers except CGNR (default: false)
  • restart::Symbol - Restart of FISTA and POGM: :none or :gradient (default: :none)
  • vary_rho::Symbol - Adaptation of rho in ADMM: :none, :balance or :PnP (default: :none)

Examples

# With L1 + Wavelet regularization
params = LeastSquaresSolverParameter(solver = FISTA,
  regParams = RegularizationParameters(
    reg = L1Regularization(1e-3),
    sparsityParams = SimpleSparsityParameters("Wavelet")
  ),
  iterations = 100
)

# Multiple regularization terms (ADMM)
params = LeastSquaresSolverParameter(solver = ADMM,
  regParams = RegularizationParameters(
    reg = [L1Regularization(1e-3), L2Regularization(1e-4)],
    sparsityParams = SimpleSparsityParameters(["Wavelet", "nothing"])

RegularizationParameters{R, S} <: AbstractImageReconstructionParameters

Parameters specifying regularization terms and their sparsity transforms.

Type Parameters

  • S - Sparsity parameters type

MRIReco.RegularizationParameters — Method
(params::RegularizationParameters)(algo, solver::Type{<:AbstractLinearSolver})

Transform the regularization parameters for a specific solver type. ADMM and SplitBregman take several terms; FISTA, POGM and OptISTA take one term; CGNR takes one L2Regularization and ignores its transform. FISTA, POGM, OptISTA and CGNR also take the projections PositiveRegularization and RealRegularization.

Arguments

  • algo::AbstractIterativeMRIRecoAlgorithm - The reconstruction algorithm
  • solver::Type{<:AbstractLinearSolver} - The solver type (for example ADMM or FISTA)

Returns

  • For ADMM and SplitBregman, which take the transforms separately: the tuple (reg, regTrafo) with one transform per term, the identity of one image for a term without a transform
  • For the other solvers: the vector of terms, each term with a transform as a TransformedRegularization

Note

  • Gets the reconstruction size and the storage type from the MRIRecoContext of the reconstruction

MRIReco.SimpleSparsityParameters — Type
SimpleSparsityParameters{S} <: AbstractSparsityParameters

Parameters specifying sparsifying transforms by name, see SparseOp.

Fields

  • sparseTrafo::S - The transform of the first regularization term ("Wavelet", or "nothing" for the identity) or a vector with one entry per term. MRIReco.applySubspace — Method
applySubspace(I, basis)

computes the echo images from the coefficient maps I of the reconstruction type "multiCoilMultiEchoSubspace", by multiplying the dimension of the coefficient maps with basis'.

I has the dimensions x, y, z, coefficient maps, coils and repetitions. basis is the matrix passed as :basis, with one row per echo and one column per coefficient map, and has the element type of I. The result has the dimensions of I, with the echoes instead of the coefficient maps.

MRIReco.decorrelateSenseMaps — Method
decorrelateSenseMaps(L_inv, senseMaps, numChan)

multiplies the coil sensitivities senseMaps, an array of size (x, y, z, coils) with numChan coils, by L_inv' from the right along the coil dimension, reshape(senseMaps, :, numChan) * L_inv', which decorrelates them in the same way as the data. L_inv is the inverse of the lower Cholesky factor of the matrix that covariance returns. If L_inv is nothing, senseMaps is returned unchanged.

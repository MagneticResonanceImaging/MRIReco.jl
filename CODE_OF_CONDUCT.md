# Code of Conduct

MRIReco.jl follows the [Julia Community Standards](https://julialang.org/community/standards/). They apply to all spaces of this project, including issues, pull requests and GitHub Discussions.

If you have a conflict or concern that needs to be resolved, you can contact the [Julia Community Stewards](https://julialang.org/community/stewards/) at stewards@julialang.org. Reports can be made confidentially.
